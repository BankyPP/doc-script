  • Saltatory conduction = กระโดดที่ node of Ranvier (myelin) → เร็ว; demyelination → CV ช้า

Electrodiagnosis ของ PNS (NCS · RNS · EMG)p.16

  • SNCV = distance / latency · MNCV = distance(S1→S2) / (latency2 − latency1)

GBS – AIDP (typical)p.5–6

Acute inflammatory demyelinating polyradiculoneuropathy (root + nerve) · non-length dependent
  • Paresthesia มือ/เท้า นำมาก่อน
  • Ascending generalized weakness (proximal ≥ distal)
  • Facial diparesis / diplegia
  • Markedly ↓ / absent DTR (areflexia)
  • Autonomic dysfunction (HR/BP labile) · denervation pain

Variants

  • AMAN (motor axonal) – C. jejuni · AMSAN (motor-sensory axonal)
  • Miller-Fisher = GBS + ophthalmoplegia → Triad: absent DTR + ophthalmoplegia + ataxia
  • Bickerstaff encephalitis = MFS + brain (↓LOC) · Pharyngeal-cervical-brachial · Acute pandysautonomia

Infection/trigger

  • Bacteria: C. jejuni (G−, watery-bloody diarrhea), H. influenzae, M. pneumoniae
  • Virus: HIV, VZV, HEV, HBV, HCV, CMV · influenza vaccine · COVID-19 vaccine (?)
  • Mechanism: molecular mimicry → activation of anti-ganglioside Ab (cross-react)

Investigations

  • LP (must) → albumino-cytologic dissociation (protein ↑↑, WBC ปกติ/mild pleocytosis; aseptic profile)
  • NCS/EMG → confirm type (demyelinating vs axonal), severity
  • Anti-ganglioside Ab (anti-GQ1b ใน MFS)
  • !! Rule out GBS-mimics: ETKA/TPPE → dry beriberi; urine porphobilinogen → porphyria

กลุ่ม MYOPATHY

Motor unit · Denervation vs Myopathyp.11

  • Motor unit = 1 motor neuron + muscle fibers ที่มันเลี้ยง; fiber ใน unit เดียวกัน = type เดียวกัน; fine movement = unit เล็ก
  • Denervation/reinnervation → fiber-type grouping; EMG giant MUAP
  • Myopathy → fiber เสียกระจาย; EMG small, short, polyphasic MUAP

Myopathy classification & clinicalp.11–12

  • Inflammatory (autoimmune, CPK↑): polymyositis, dermatomyositis, IMNM/NAM, overlap (muscle × rheumato), idiopathic
  • Non-inflammatory: statin-associated, periodic paralysis (hypo-K, เป็นพัก ๆ), thyroid myopathy
  • Dystrophy: congenital, DMD, BMD (X-linked recessive); Gowers sign
Generalized weakness proximal > distalpainful (inflam) / painlessmildly ↓DTR± ↑CPKno sensory deficit

Dermatomyositis

  • Perivascular inflammation ที่ perimysium → vessel → skin + muscle
  • Gottron’s papules · Heliotrope rash · V-sign / shawl (photosensitive)
  • Paraneoplastic → screen CA
กลุ่ม MOTOR NEURON DISEASE · UMN/LMN

Pyramidal pathwayp.12, 14

Motor cortex (UMN)→Corona radiata→Internal capsule→Brainstem (corticobulbar → CN nuclei)→Pyramid decussation (medulla)→Lat. corticospinal tract→Ant. horn cell (LMN)→root → plexus → nerve → NMJ → muscle

ALS (Lou Gehrig’s disease)p.12–13

  • UMN + LMN signs ร่วมกัน, fasciculation, NO sensory deficit
  • Degeneration lateral corticospinal tract + ant. horn cells
  • Dx: EMG (neuropathic pattern, หลาย segment) · marker: neurofilament
  • cf. polio, SMA = LMN only
